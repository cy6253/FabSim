# FabSim3D — 참조 구현 및 검증 스크립트

TypeScript 이식의 **참조 구현**과, 설계 결정을 뒷받침한 수치 검증 스크립트입니다.
전부 순수 Python 3이며 외부 의존성이 없습니다 (`python <파일>` 으로 바로 실행).

## 참조 구현

| 파일 | 내용 |
|---|---|
| `m1a_core.py` | **3D 코어.** 원시연산 P1(EDT + feature transform, FMM)·P2(연결성)와 기판·증착·식각 연산자. 적대적 시퀀스를 실행하고 불변식을 검사합니다. TypeScript 이식은 이 구조와 이름을 그대로 따릅니다. |
| `m1c_uf_check.py` | φ 진리원천 파이프라인 + union-find 봉인·돌파를 3D에 적용하고 sweep 판과 대조합니다. |
| `m2_litho.py` | **P3**(높이 채우기)와 **P4**(광선 투영). PR 코팅·노광·현상·PR 제거·CMP. |
| `m2_dope.py` | 이온 주입(P4 광선 + 깊이 분포)과 어닐(ADI, Crank–Nicolson). |
| `m2_thermal.py` | 산화·실리사이드. 계면 양방향 반응, Deal-Grove, 도펀트 편석. |

```
python m1a_core.py [식각시간]     # 기본 45
```

출력: 단계별 시간·보이드 수·재질 분포, 적대적 케이스 (a)(b)(c) 판정,
φ 부호 정합성, 스냅샷 RLE 크기, 전체 규모 환산.

## 검증 스크립트

각각 설계 주장 하나를 확인하고, 그 결과로 결정이 바뀌었습니다.

| 파일 | 확인한 것 | 결과 |
|---|---|---|
| `etch_monotonicity.py` | 식각의 봉인이 증착처럼 단조로운가 | 아니오. 돌파마다 재계산 필요 (결정 D) |
| `depo_approx_check.py` | EDT 근사 vs FMM 오라클, 단일 조건 | 커버리지 정확, 셀 오차 중앙값 3.1% |
| `depo_sweep.py` | 종횡비 × 커버리지 9조합 | **커버리지 오차 0%**, 핀치오프 10~14% 늦음. 오차는 커버리지에만 의존 |
| `depo_substep2.py` | 서브스테핑으로 보정되는가 | 아니오. 부울 격자에서 양자화로 전선 정지 → φ 필드가 필요한 이유 |
| `etch_multimat.py` | 다중 재질 식각에 근사가 통하는가 | 공간 동시성은 통과, **깊이 통과는 2.3배 오차** → FMM으로 전환 (결정 I) |
| `anneal_check.py` | 가변-D 확산이 얌전한가 | σ 오차 0%, 도즈 보존, 산화막 100% 차단. 명시적은 261 패스 → ADI (결정 M) |
| `phi_and_seal_check.py` | φ를 진리의 원천으로 쓸 수 있는가 | 0.46×5 = 2.3 한 번과 차이 0. union-find 봉인 20배 빠름 (결정 O·P) |

## 핵심 규칙

**EDT 근사는 표면점의 속도가 그 광선 전체에 유지될 때만 유효합니다.**
증착의 스텝 커버리지는 이 조건을 만족하지만, 식각의 선택비는 경로 중간에
재질이 바뀌므로 만족하지 않습니다. 새 연산자를 설계할 때 먼저 물을 것:

1. 이 연산은 무엇과 이어져 있어야 일어나는가 → P2 연결성
2. 속도가 경로를 따라 변하는가 → 예면 FMM, 아니면 EDT
3. **검증이 실패하면 구현을 고치기 전에 "이 단언이 맞는 물리인가"부터 묻습니다.** 지금까지 실패의 절반이 코드가 아니라 단언 쪽이었습니다 — 보이드를 총량으로 비교, 도즈를 한 컬럼으로 측정, 표면 근처 σ를 자유공간 공식과 비교 등.
