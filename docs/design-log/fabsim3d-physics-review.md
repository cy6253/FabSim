앱이 완성된 뒤(M5, 3D 주 화면까지) 처음으로 **물리 모델만** 따로 떼어 검토했다.
기준은 `web/app/src/core/ops/*.ts`와 `core/data/*.json`의 **지금 코드**이고, 설계 로그의
결정(I~R)과 대조했다. 이 문서는 구현 지시서다 — 구현은 Opus 5가 맡고, 각 항목은
**2D 파이썬 검증 → 코어 반영 → 골든 테스트** 순서를 지킨다([[fabsim3d-design-first]]).

원칙은 바뀌지 않는다([[fabsim3d-goal]]): TCAD가 아니다. 물리 PDE를 더 푸는 것이 아니라,
**학생이 화면에서 보는 것이 실제 공정과 어긋나는 자리**를 고친다. 판단 기준 셋 —
①자유 조합에서 깨지지 않는가 ②노브 하나가 개념 하나에 대응하는가 ③화면에서 읽히는가.

그게 맞는 답이다. 창을 22로 좁혀 1.6으로 옮기니 다시 닫혀 18,153셀이 갇힌다 — 예제가

가시성으로 쟀다. 그런데 수직 벽 트렌치의 바닥은 바로 위가 뚫려 있어 이온이 그대로 닿는데도
반구로 재면 "절반쯤 가려짐"으로 나온다. 그래서 창의 가시성 분포가 깊이에 그대로 찍혀
이방성 1에서 바닥이 **9복셀이나 사발처럼 팼다**(이방성 1은 측면 속도가 거의 0이라 한번
생긴 굴곡이 절대 안 펴진다). 원인은 이온 원뿔의 폭을 이방성과 무관하게 둔 것이었다.
원뿔이 지향성을 따라 좁아지게 하니 편차가 1복셀로 돌아왔다.

그 정정으로 **RIE lag 주장은 철회한다.** 잘 정렬된 이온 빔에는 종횡비 의존성이 원래 없다 —
실제 lag은 등방으로 오는 **중성 라디칼**의 수송 제약에서 나오고, 이 모델에는 그 항이 없다.
결정 R이 "가시성 ∝ 수직 성분"으로 둘을 한꺼번에 얻을 수 있다고 본 것이 과했다. 넣으려면
이온·중성 두 성분 모델이 필요하고, 그건 별도 항목이다.

**참조 구현도 같이 옮겼다.** 프로토타입(`m2-ops.html`)과 파이썬 오라클이 §1·§2·§4·§5의
같은 결함을 갖고 있었다. 셋을 함께 고쳐 parity가 비트 동일로 유지되고 오라클이 오라클로
남는다 — 한쪽만 고치면 매 실행이 실패해 신호가 죽는다.

## 1. 산화 성장의 컬럼 게이트 (결함, 실측)

**현상.** `thermal.ts` `opOxidize`:

```ts
const active = new Uint8Array(NX * NY);
for (const i of consumed) active[XOF(s, i) + NX * YOF(s, i)] = 1;
…
if (mat[i] === EMPTY && reach[i] && dOff[i] <= gd && active[column]) grown.push(i);
```

성장 후보는 "**어느 고체**로부터든 gd 안에 있는 진공 ∩ 소비가 일어난 **컬럼**"이다.
LOCOS에서 산화제는 패드 산화막을 타고 질화막 아래로 lOx(=x≈18)만큼 기어 들어가
그 아래 Si를 소비한다 → 그 컬럼들이 active → 그 컬럼의 진공 중 질화막 **윗면**에서
gd 안에 있는 칸이 산화막이 된다. 결과는 질화막 마스크 위에 두께 gd의 산화막 캡이
창 양쪽 18복셀 폭으로 깔리는 것이다.

**실측 (LOCOS 예제, 208×64×88, 9단계 wet1100):**
- 성장 90,624셀 중 **24,576셀(27%)이 질화막 위**. 컬럼 2,688/13,312(20%).
- 캡 두께 min 9 / median 9 / max 12 — 예측값 gd = 17.99×(1−1/2.17) = 9.7과 일치.
- **하류 효과:** 10단계 인산(SiO2 선택비 0.025)이 캡을 못 뚫어 **질화막 5,120셀이
  살아남는다**(45,312 → 5,120, 정답은 0). 3D 화면에서 창 가장자리에 청록 덩어리로
  보이는 것이 이것이다. 즉 LOCOS 예제의 최종 구조가 틀렸다.

이건 [[fabsim3d-column-assumption]]이 경고한 바로 그 함정이다 — 산화 계면은 컬럼이
아니라 **면**이고, 성장은 소비가 일어난 계면에서 바깥으로 일어난다.

**제안.** 컬럼 게이트를 버리고 **거리 게이트 둘**로 바꾼다.

```
dC   = EDT(consumed 집합)            // 소비된 칸까지의 거리
dOff = EDT(solid)                    // 지금 고체 표면까지의 거리 (이미 있음)
grown = vacuum ∩ reach ∩ (dOff ≤ gd) ∩ (dC ≤ gd + lOx)
```

- `dOff ≤ gd`: 표면에서 gd만큼만 올라간다(지금과 같음).
- `dC ≤ gd + lOx`: **소비가 일어난 곳 근처에서만**. lOx는 패드 산화막을 건너는 여유다
  (패드 위에 자라는 것은 맞다 — 새 산화막은 계면에 생겨 위를 밀어올린다).
- 질화막 윗면은 소비 지점에서 질화막 두께 + 패드 두께만큼 떨어져 있어 gd+lOx를 넘는
  경우가 대부분이지만, **얇은 질화막에서는 아니다**. 그래서 추가 조건 하나:
  `grown` 칸에서 아래로 내려갈 때 처음 만나는 고체가 `oxidantPermeable`이거나
  소비된 칸이어야 한다 — 질화막 위는 첫 고체가 질화막이라 걸러진다. 컬럼 연산이지만
  "이 칸 바로 아래가 무엇인가"라는 국소 질의라 컬럼 가정이 아니다.

EDT가 한 번 늘어난다(2→3). 산화는 드문 연산이라 예산 안이다.

**부수 이득.** 수직 측벽(트렌치 라이너, 게이트 측벽 재산화)에서 **바깥으로** 자라는
산화막이 지금은 "옆 컬럼에 우연히 소비가 있었을 때만" 생긴다. 거리 게이트는 이걸
방향과 무관하게 맞게 한다.

**검증 (2D 스크립트 먼저).**
1. 질화막 마스크 + 패드 산화막 → 산화: **마스크 위 산화막 0**, 창 안 두께 x±1, 마스크
   아래 침투 ≤ lOx (기존 골든 유지).
2. 수직 Si 벽 → 산화: 벽 안쪽 소비 cd, 벽 바깥 성장 gd, 합이 바닥과 같다(±1).
3. 패드 산화막 위 재산화: 패드 위에 자란다(지금 동작 유지).
4. LOCOS 예제 최종 프레임 **질화막 = 0** 을 골든에 추가. 이 단언이 없어서 놓쳤다.

## 2. x0 = 0 (결함)

**현상.** `dealGrove(ambience, seconds, x0)`는 기존 산화막 두께 x0를 받아 τ 보정을
하지만 `opOxidize`는 `dealGrove(ambience, seconds, 0, …)`로 부른다. 주석은 "두 번째
산화가 처음보다 느린 이유"라고 x0를 설명하고 있는데 값이 안 들어간다. 패드 산화막
위 필드 산화, 게이트 재산화가 전부 **맨 Si인 것처럼 빠르게** 자란다. 얇을수록 오차가
크다(선형 구간).

**제안.** 소비 계면의 **기존 산화막 두께를 재서** x0로 넘긴다.
- 계면 칸(소비될 Si에 6-인접한 산화제 점유 칸) 각각에서 "진공까지 산화막을 지나는
  거리"를 재면 그것이 국소 x0다. `oxidantReach`가 이미 hop 수를 세고 있으니 hop 수를
  같이 기록하면 공짜다.
- 1차: **중앙값 하나**를 스칼라 x0로 쓴다. Δx = dealGrove(t, x0) − x0 만 이번 단계에
  소비·성장한다. 2차(선택): 컬럼별 x0 → 컬럼별 Δx. 1차만으로 교육 목적은 충분하다.
- 산화막이 없으면 x0 = 0 (지금과 동일 → 회귀 없음).

**검증.** 같은 조건 두 번 산화 = 두 배 시간 한 번 산화 (±1복셀). 지금은 두 번이 더
두껍다. 예제의 `s.ox()`는 x0=0 기준이라 **두께 재보정 필요**(LOCOS 필드 산화, STI 패드
위 라이너). 어느 예제가 얼마나 얇아지는지 먹여 보고 초를 올린다.

## 3. baseRate · removal 미사용 (데이터-코드 불일치)

**현상.** `processes.json`은 식각액마다 `baseRate`(BOE 3.0, 인산 2.0, 피라냐 5.0), 슬러리마다
`removal`(SiO2 1.0, Si3N4 0.15, polySi 0.5 …)을 갖지만 `executor.apply()`는 `seconds`를
그대로 `opEtch`에 주고 `opCMP`는 `stopOn`만 본다. 표를 편집하는 화면(LibraryEditor)에는
이 값들이 보이지 않으니 지금 당장 사용자를 속이는 것은 아니지만, **표가 약속하는 물리와
코어가 다르다.** 재질·공정 표 결정("값은 데이터")의 정신에 어긋난다.

**제안 — 식각.** `baseRate`를 적용한다: 유효 시간 = seconds × baseRate. 같은 10초에
BOE는 30복셀, RIE는 10복셀 — "습식은 빠르고 제어가 어렵다"가 노브에서 읽힌다.
노브 이름은 "시간"으로 두고 결과 줄에 제거 깊이를 이미 찍고 있다.
- 예제가 `seconds: s.L(…)`로 **깊이를 초에 직접** 박아 뒀다. 도우미 `s.etch(etchant, depth)
  = depth / baseRate`를 추가해 전부 바꾼다. 안 바꾸면 BOE 단계들이 3배 깊어진다.
- 대안(비추천): `baseRate`를 스키마에서 지운다. 정직하지만 배울 것이 하나 줄어든다.

**제안 — CMP.** §9와 묶는다. 최소한은 `removal`에 없는 재질을 "안 깎임"으로 다루는
것(지금은 stopOn 외 전부 깎인다). 그 이상은 §9.

## 4. 식각 방향성과 ARDE (결정 R 구현)

**현상.** `opEtch`는 이방성을 FMM의 축별 간격 `H = (1/lat, 1/lat, 1)`으로 표현한다.
이 타원 메트릭은 ±z에 대칭이라 **오버행 밑면도 이온 속도 1로 위를 향해** 판다.
실제 RIE는 이온이 위에서 오므로 그림자 아래는 화학 성분(측면 속도)만 남는다.
트렌치 예제의 스퍼터 립 아래, 언더컷 PR 아래가 이 경우다. 또 종횡비 의존 식각(RIE
lag)이 없어 넓은 홀과 좁은 홀이 같은 깊이로 파인다. 결정 R("가시성을 재사용해 수직
성분 ∝ 가시성")이 설계 로그에는 있으나 코드에는 없다.

> **구현 결과 정정 (2026-09-05).** 아래 제안 중 "가시성"을 반구 평균으로 읽으면 안 된다.
> 그러면 수직 벽 트렌치의 바닥이 그늘로 잡혀 바닥이 사발처럼 팬다(α=1에서 9복셀). 이온
> 원뿔의 폭이 **이방성을 따라 좁아져야** 한다 — `visibility`에 cosⁿ 가중을 넣고
> n = α/(1−α)로 뒀다. 그리고 그 원뿔이 좁아지면 **RIE lag은 나오지 않는다**(아래 ②는
> 성립하지 않는다). 잘 정렬된 빔에는 종횡비 의존성이 없기 때문이고, 실제 lag은 등방
> 중성 라디칼 쪽 이야기다. ①③④는 그대로 성립한다.

**제안.** 수직 속도만 가시성으로 게이트한다 — FMM에 **칸별 hz**를 허용하면 끝난다.

```
V(i)  : 전선 칸의 하늘 가시성 (visibility(), NRAY=12, RAYLEN=26 — 증착과 같은 상수)
       → feature transform으로 고체 칸에 배정 (증착과 같은 방식)
hz(i) = 1 / (lat + (1−lat)·V(i))        hx = hy = 1/lat (전역, 지금과 같음)
```

- V=1(개방): 수직 sel, 측면 sel·lat — **지금과 동일** (회귀 없음).
- V=0(완전 그림자): 수직 sel·lat, 측면 sel·lat — **등방 화학 식각만** 남는다. 맞다.
- 좁은 트렌치 바닥 V<1 → 느리다 = RIE lag. 노브를 추가하지 않고 얻는다.
- α=0(습식): lat=1 → hz=1, V와 무관 → **지금과 완전히 동일**. 습식은 건드리지 않는다.

`fmm3`의 `solve()`는 `H[k]`를 전역으로 읽는다. `hz`를 `Float32Array | number`로 받아
`ah[n] = typeof hz === "number" ? hz : hz[i]` 한 줄이면 된다. 갱신되는 칸의 메트릭을
쓰므로 Godunov 스킴은 그대로 유효하다. 속도를 한 단계 시작 시점에 얼려 쓰는 근사는
증착과 같은 종류다([[fabsim3d-verification-log]] "EDT 근사가 통하는 조건" — 이온의
수직 통로는 한 단계 안에서 거의 유지된다).

**검증.** ①오버행 아래 식각: 립 밑면이 위로 파이지 않는다(α=0.9에서 밑면 후퇴 ≤
lat×t) ②폭 다른 트렌치 둘, 같은 시간 → 좁은 쪽이 얕다 ③α=0 결과가 현재와
비트 동일(parity) ④평평한 개방면 α=1이 현재와 동일. `etch` 노드 `teaches`에 "RIE
lag" 한 줄 추가.

## 5. 실리사이드 — 계면 인접성 · 선택 금속 제거

**현상 1.** `opSilicide`는 `dSi = EDT(금속 전체)`, `dMe = EDT(반도체 전체)`를 쓴다.
사이에 산화막이 있어도 **거리만 맞으면 반응**한다. 두께 3(tS≈1.9)에서는 1복셀 산화막을
못 넘지만, 두께 4 이상이면 넘는다. 검증 기록의 "산화막 위 72셀(가장자리 1복셀 침투)"이
이 누출이다. "산화막 패턴만으로 배치된다"가 이 연산자가 가르치는 전부인데, 그 산화막을
건너뛰면 개념이 무너진다.

**제안.** EDT의 소스를 **계면 쌍**으로 좁힌다: `src_M = {금속 칸 | 6-인접에 반도체}`,
`src_S = {반도체 칸 | 6-인접에 금속}`. 산화막으로 분리된 곳은 계면 쌍이 없어 반응이
0이 된다. 코드 변경은 소스 마스크 만드는 루프 하나.

**현상 2.** 라이브러리에 **미반응 금속만 벗기는 습식 식각액이 없다**(NH4OH/H2O2 계열).
`RIE_metal`은 건식이고 TiSi2 선택비가 없다. 그래서 NMOS 예제는 13단계 실리사이드에서
**미반응 Ti를 남기고 끝난다**(최종 프레임 범례에 Ti 존재). 산화막 위 Ti가 게이트와
S/D를 잇는 상태다. `allops` 예제는 대신 `slurry_tungsten` CMP로 금속을 걷어내는데,
실제 살리사이드 흐름은 CMP가 아니라 선택 습식이다.

**제안.** `processes.json`에 추가:
```json
{ "id": "metal_strip", "name": "미반응 금속 제거 (NH4OH/H2O2, 습식)", "phase": "wet",
  "anisotropy": 0.0, "baseRate": 2.0,
  "selectivity": { "Ti": 1.0, "TiN": 1.0, "Co": 1.0, "Metal": 1.0, "TiSi2": 0.0, "CoSi2": 0.0, "MetalSi": 0.0, "SiO2": 0.0 },
  "teaches": "실리사이드는 남기고 산화막 위 금속만 벗긴다 — 살리사이드의 마지막 단계" }
```
NMOS 예제 14단계로 붙이고, 진단에 "실리사이드 뒤 미반응 금속 잔존" 검사를 넣는다
(silicide 다음 프레임에 금속 `kind`가 남아 있고 그 뒤에 제거 단계가 없으면 warn).

## 6. PVD 증착의 방향성

**현상.** `visibility()`는 상반구를 **Lambert(cos) 분포**로 고정 표본화하고 탈출 비율만
잰다. 커버리지 c는 `rate = c + (1−c)·V`로 섞는다. 두 가지가 빠져 있다.
- **입사 분포의 폭.** CVD(열 가스)는 Lambert가 맞지만 스퍼터는 좁고 증발은 거의 수직이다.
  증발(c=0.12)에서 개방 트렌치 측벽은 하늘의 절반을 보므로 `rate ≈ 0.12 + 0.88×0.5 = 0.56` —
  "측벽에 거의 안 붙어 리프트오프에 쓴다"는 설명과 반대다. 언더컷 PR 측벽이 코팅되어
  **리프트오프 실습이 성립하지 않는다.**
- **표면 법선.** 벽과 바닥이 같은 하늘을 보면 같은 속도다. 실제 플럭스는 n̂·d̂에 비례해
  수직 벽은 스치는 광선에서 거의 못 받는다. 그래서 PVD는 위에 두껍고 벽에 얇고 입구에
  빵덩이(bread-loaf)가 선다.

**제안.** 둘 다 `visibility()` 안에서 끝난다. 노브는 추가하지 않는다.
- `DepositionDef`에 `exponent` n 추가(데이터만): ALD/LPCVD/PECVD 1, sputter 4, evaporation 12.
  광선 가중 w_r = cosⁿθ_r. (표본을 cosⁿ에서 뽑는 대신 가중치를 주면 방향 집합이 그대로
  결정적이다.)
- 각 탈출 광선에 max(0, n̂·d̂)를 곱한다. n̂은 ∇φ — `opDeposit`은 `ensurePhi` 직후라
  **φ가 항상 유효**하다. 정규화는 개방 평면(n̂=ẑ, 전부 탈출)의 값으로 하여 평면 속도 1을
  유지한다.
- 그러면 `rate = c + (1−c)·F`, F ∈ [0,1]. 컨포멀(c=1)은 F와 무관 → 회귀 없음.

**검증.** ①언더컷 PR 위 증발: 측벽 두께 ≤ 상면의 15%, 리프트오프 후 패턴 남음
②스퍼터 트렌치: 입구 립이 서고 핀치오프가 지금보다 이르다(검증 기록의 "10~14% 늦음"이
줄어드는지) ③c=1(ALD) 비트 동일 ④LPCVD 측벽/상면 비 0.85~0.95(실제 값대).

## 7. 이온 주입 측면 산포

**현상.** `opImplant`는 컬럼마다 깊이 가우시안만 놓는다. 마스크 가장자리에서 도핑이
수직으로 딱 끊긴다. 실제는 측면 산포 σ_lat ≈ 0.5~0.7·ΔRp로 마스크 밑으로 번지고, 그것이
**게이트-S/D 겹침(유효 채널 길이)**을 정한다 — NMOS 예제가 가르쳐야 할 개념이다.

**제안.** 도즈 가중치를 3D 가우시안 `G_z(d−Rp)·G_lat(Δx)·G_lat(Δy)`으로 놓는다. 깊이 d는
**출발 컬럼의 진입점** 기준(이온의 경로 기준이 맞다). σ_lat = 0.6·ΔRp, 반지름 3σ. 고체 칸에만
놓고 컬럼별로 정규화해 도즈를 정확히 보존한다(진단 `dose-not-conserved`가 이미 지킨다).
비용: 마스크 열린 컬럼 × (6σ)² ≈ 열린 컬럼당 수십 이웃. 노브 추가 없음(ΔRp가 둘을 다 정한다).

**검증.** 창 가장자리 프로파일이 erf 모양(폭 σ_lat), 총 도즈 보존 100%, 마스크 닫힘·열림 두
컬럼의 합이 변하지 않음. NMOS 채널 아래 도핑 그래프에서 겹침이 보이는지 눈으로.

## 8. 어닐 노브 — 온도·시간으로

**현상.** `anneal` 노드의 노브가 `steps`·`dt`다. 이것은 **ADI의 수치 파라미터**이고 학생이
알 필요가 없는 값이다. 한편 `materials.json` 종 표에는 `D0`·`Ea`가, 산화 조건 표에는
`temperature`가 이미 있는데("온도 노브를 붙일 때 쓴다") 코어는 `relD` 상수만 쓴다.
또 **산화·실리사이드 같은 고온 단계가 도펀트를 전혀 움직이지 않는다** — 필드 산화가
채널스톱 주입을 밀어 넣는 것이 LOCOS 실습의 일부다.

**제안.**
- 노브를 `temperature`(select 800/900/1000/1100) + `seconds`로. 내부에서
  `D_sp(T) = D0·exp(−Ea/kT)`, `Dt = D·t·κ`, κ는 **단 하나의 전역 보정 상수**(복셀² 단위로
  맞추는 값)로 `processes.json`에 둔다. `relD`는 삭제 — 온도에서 나온다(B/P/As 비율이
  온도에 따라 바뀌는 것도 맞다).
- ADI `steps`/`dt`는 코어가 정한다: CN이 정확한 범위(검증 기록 Dt=8을 2스텝)로 dt ≤ 4를
  잡고 steps = ⌈Dt/dt⌉. 사용자에게 안 보인다.
- `oxidize`는 자기 `temperature`·`seconds`로 **같은 확산을 암묵적으로 수행**한다(산화
  뒤에 `opAnneal` 호출). `silicide`는 저온(600~800)이라 생략 가능.
- 파일 호환: 옛 프로젝트의 `steps·dt`는 로더에서 `Dt`로 환산해 temperature=1000, seconds
  역산으로 이주한다.

**검증.** 자유공간 σ = √(2Dt) 0% 오차 유지(기존 오라클), Dt 같으면 옛 노브와 비트 동일,
LOCOS 산화 뒤 채널스톱 B 프로파일이 깊어진다.

## 9. CMP 디싱·침식

**현상.** `opCMP`는 전역 평면 `gmax − amount`까지 컬럼을 깎고 `stopOn` 재질에서 멈춘다.
`removal` 속도표는 안 쓴다(§3). 그래서 정지층에 닿은 뒤에는 **어느 컬럼도 더 깎이지
않는다** — 실제 STI/다마신에서 가장 중요한 결함인 **디싱**(넓은 산화막이 질화막보다
낮게 파임)과 **침식**(정지층도 조금 깎임)이 안 나온다.

**제안(2단계).** amount 중 정지층 평면 위 부분은 지금처럼 전부 깎는다. 정지층 평면
아래로 남은 양 `over`가 있으면(과연마), 비정지 재질을 `over × r_mat / r_stop`만큼 더
깎되 슬러리별 `maxDish`(복셀)로 자른다. `slurry_oxide`: SiO2 1.0 / Si3N4 0.15 → 산화막이
질화막의 6.7배 깎여 디싱, 질화막은 `over×1`만 깎여 침식. 패턴 폭 의존은 넣지 않는다
(TCAD 영역). 새 진단: "과연마 — 디싱 N복셀". 노브는 그대로(`amount`가 곧 과연마 정도).

**검증.** 정지층 없음 → 지금과 동일. 정지층 있고 over=0 → 지금과 동일. over>0 →
산화막 창이 질화막보다 ≤ maxDish 낮다.

## 10. 데이터 — 확산 배수

`Metal·W·TiN·Ti·Co·Al·Cu·PR·PR_exposed·MetalSi·TiSi2·CoSi2`의 `diffusionFactor`가 전부 1이다.
도펀트가 텅스텐과 레지스트 속으로 Si와 같은 속도로 퍼진다. 금속·레지스트 **0.01**,
실리사이드 **0.2**(실제로 도펀트가 실리사이드로 빠지는 "도펀트 손실"이 있다)로 바꾼다.
한 줄짜리 데이터 수정이고 회귀 위험은 어닐 골든의 총량 보존만 다시 보면 된다.

## 11. 표시 — 복셀당 nm

길이가 전부 복셀이라 학생이 "이 트렌치가 200 nm인지 2 µm인지"를 못 잇는다. 프로젝트에
`nmPerVoxel`(기본 10) 하나를 두고 단계 바·프로브·노브 단위에 `21 복셀 (210 nm)`처럼 병기한다.
코어는 건드리지 않는다. 격자 프리셋을 바꾸면 예제는 비율로 쓰므로 nm이 유지되게 함께
스케일한다.

## 하지 않는 것 (범위 밖 — 다시 제안하지 말 것)

- **공중상(aerial image)·회절·근접 효과.** 노광은 수직 광선 + 이진 마스크로 남는다(결정 ⑧).
- **응력·질화막 들림(bird's beak lift).** §1은 마스크 위 캡을 없애는 것이지 질화막을 밀어
  올리는 것이 아니다. 고체는 서로를 움직이지 않는다.
- **KOH 결정 방향 의존.** 결정 B 그대로 보류. 훅만 남아 있다.
- **농도 의존·산화 촉진 확산, 클러스터링.** 어닐은 종별 상수 D(T)로 충분하다.
- **CMP 패턴 밀도 의존.** §9의 `maxDish` 상수로 끝낸다.
- **봉인된 노광 PR의 현상 불가.** 현상은 연결성을 보지 않는다. 광선 모델에서 이 경우는
  거의 안 생긴다. 생기면 진단으로만.
