FabSim3D 논의에서 사용자에게 결정을 물을 때는 **간략하게** 묻는다 (2026-09-04 요청). 긴 배경 설명·비용 분석·양쪽 논거를 늘어놓은 뒤 질문하는 방식을 사용자가 명시적으로 줄여달라고 했다.

**Why:** 사용자는 가이드 역할이라 판단에 필요한 최소 정보만 있으면 되고, 긴 설명은 오히려 결정을 늦춘다.

**How to apply:** 선택지와 핵심 트레이드오프 한 줄씩, 추천 하나. 상세한 근거는 사용자가 물으면 그때 제시한다. 결정 사항 정리도 표나 짧은 목록으로.
