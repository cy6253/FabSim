2026-09-04 확정: FabSim3D의 **공정 노드 12개는 원시연산 4개** 위에 올라간다. 명세 문서: https://claude.ai/code/artifact/5723e6a5-3f5b-470a-9c1e-5ca273f499f5

**원시연산 4개** (앞서 셋이라고 했다가 마스크 투영이 별개임을 발견해 정정):
1. 거리 오프셋 — 증착, 식각, 어닐, 산화. 축별 가중치로 이방성, 표면점별 속도로 불균일 성장
2. 연결성 검사 — 증착 봉인, 식각 도달, PR 채움 범위, 어닐 경계 ([[fabsim3d-connectivity-primitive]])
3. 높이 기준 채우기/자르기 — PR 코팅, CMP
4. 마스크 투영 — 노광, 이온 주입

**핵심 노브 설계** (노브 하나 = 가르치는 개념 하나):
- 증착: 스텝 커버리지 % (컨포멀 ↔ PVD 오버행·보이드)
- 식각: **이방성 비율 하나로 dry/wet 통합** (1.0=수직 RIE, 0.0=등방 습식). 노드를 둘로 나누지 않는다. 구현은 거리 지도의 축별 가중치만 변경
- PR 코팅: 평탄화 정도 (0%로 두고 단차 위에 노광하면 왜 CMP가 필요한지 보임)
- 현상: positive/negative 전환 — 같은 마스크로 정반대 패턴

**A/B/C 결정:**
- **A. 도핑 = 종별 농도 필드 2~3개** (붕소·인·비소 Float32), 화면엔 net doping 표시. 어닐은 처음에 가우시안 블러로 정했으나 **결정 M에서 ADI로 교체**됐다 — 블러는 D가 일정하고 경계가 없을 때만 정확한데, 산화막 확산 장벽과 표면 무유출을 다루려면 가변-D가 필요하다. 스냅샷은 도핑 존재 영역의 바운딩 박스만 저장. 프로파일 그래프 UI가 새로 필요.
- **B. 결정 방향 이방성 습식 식각 = 중간안.** 지금은 등방만, 법선 의존 속도 함수를 끼울 훅만 남긴다(증착 구조 재사용이라 비용 0). MEMS를 다루기로 하면 하루 추가.
- **C. 마스크 정렬 오차 dx/dy 노브 = 넣는다.** 반나절, 오버레이 오차 실습용.

**Fable 독립 검토 후속 (결정 I~N):** 원시연산은 여전히 4개이나 **P1을 계면 일반형으로 다시 정의**했다(산화·실리사이드는 재질 계면에서 양방향 오프셋). 다중 재질 식각은 **FMM으로 전환**(EDT 근사가 2.3배 오차). CMP에 **도달 가능성 P2 추가**(오버행 아래 묻힌 재질 연마 방지). 이온 주입은 **광선 기반**으로(오버행 그림자가 공짜로 따라옴). 어닐은 **ADI**. 산화가 Si를 먹을 때 **종별 편석 계수로 도펀트 재배치**. 자세한 근거는 [[fabsim3d-verification-log]].

**미결:** 성능 실측(벤치마크 대기), LOCOS bird's beak 포함 여부, M1을 적대적 케이스로 재설계.

**2차 검토 추가:** P1은 φ를 유지하는 연산으로 재정의(결정 O) — 컨포멀 증착·등방 식각은 EDT 없이 뺄셈. 식각에 **ARDE(종횡비 의존 식각) 노브** 추가(결정 R): 증착의 가시성 기계장치를 재사용해 수직 성분 속도 ∝ 가시성. 비용 거의 0, 가르치는 개념 하나(RIE lag). 미검증 항목: 이방성 α에서 사이드월 기울기 = (1−α)가 실제로 나오는지.
