2026-09-04 결정: FabSim3D의 증착 연산자는 **거리 지도(EDT) + 스텝 커버리지** 방식으로 간다.

세 안을 2D 데모로 비교한 뒤 사용자가 3안을 선택했다 (데모: https://claude.ai/code/artifact/cb8a6892-005a-4afe-a88f-b73c8d29b3f7):
1. 8-이웃 확산 — 현재 코드 방식. 대각선을 "한 칸"으로 세서 45° 방향이 41% 과성장 (3D의 18-이웃도 동일한 41%)
2. 거리 지도 · 컨포멀 — 모든 방향 동일 성장. 보이드는 안 생김 (균일 증착만으로는 원래 안 생기는 게 맞음)
3. **거리 지도 + 스텝 커버리지** ← 채택. 깊은 곳일수록 하늘이 덜 보여 느리게 자라고, 입구가 바닥보다 먼저 막혀 보이드가 갇힌다

**구현 방침 — FMM은 쓰지 않는다.** 3D 600만 복셀에서 FMM은 3~8초로 너무 비싸다. 대신:
- EDT에 **feature transform**(각 칸의 가장 가까운 표면점 인덱스)을 같이 계산 — 배열 하나 추가로 사실상 공짜
- 표면점마다 가시성 → 성장속도 r 을 미리 계산
- 채움 조건 = `거리 ≤ 두께 × r(가장 가까운 표면점)`

**Why:** 가시성은 프레임마다가 아니라 **공정 스텝마다** 계산하면 되므로(노드 1회 실행 = 연산 1회, 애니메이션은 임계값만 변경) 노드당 1초 수준이면 충분하다. 이 전제에서 EDT ~0.3초 + 가시성 ~0.5–1초는 감당 가능하지만 FMM만 유독 비싸다.

**How to apply:** 예상 공수 2일(3D EDT 3축 확장 + 표면점 전파 반나절, 표면 가시성 광선 반나절, 노브 연결·튜닝 하루). 근사의 한계는 표면점→칸 경로 중간에 속도가 변하는 걸 무시한다는 점이고, 트렌치처럼 완만한 구조에서는 무시 가능.

**봉인 보정이 반드시 필요하다.** 사용자가 지적해서 발견: 미리 만든 도달시각 필드만 쓰면 보이드가 자기 벽에서 계속 채워져 사라진다. 실제로는 입구가 막히면 가스가 못 들어가 그 크기로 얼어붙어야 한다. 채움 조건을 `거리 ≤ min(두께, 봉인시각)`으로 쓰고, 봉인시각은 임계값을 0부터 한 번 훑으며 각 칸이 바깥과 끊긴 시각을 기록해 얻는다. 증착은 재료를 더하기만 해 봉인이 단조롭기 때문에 한 번의 훑기로 충분하다. 자세한 내용은 [[fabsim3d-connectivity-primitive]].

**2차 검토 갱신 (결정 O·P):** 실제 메커니즘은 φ 유지다 — `φ -= t·r(최근접 표면점)`, 고체 = φ ≤ 0. 컨포멀(r=1)이면 EDT 없이 O(N) 뺄셈이고, feature transform은 r이 표면점마다 다를 때만 필요하다. 봉인 시각은 임계값 훑기(flood fill K회)가 아니라 **역시간 union-find 한 번**으로 구한다(도달시각 내림차순 삽입, 바깥과 처음 이어지는 병목값이 봉인 시각). 병합 시 연결 안 된 쪽 루트에 현재 임계값을 먼저 찍어야 한다. 검증: [[fabsim3d-verification-log]].
