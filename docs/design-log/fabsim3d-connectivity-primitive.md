거리 지도(EDT)만으로는 부족하다. **"이 칸이 바깥(ambient)과 이어져 있는가"를 묻는 연결성 검사가 여러 연산자의 공용 부품**이다. flood fill 한 번이고, 3D 600만 복셀에서 ~0.1초라 공정 스텝당 몇 번 돌려도 부담 없다.

미리 계산한 거리 지도가 담지 못하는 것은 **도중에 전달 경로가 끊기는 사건**이다. 초기 구조만 보고 정해지는 필드에는 그 정보가 없다.

연산자별로 조건이 다르다:
- **증착** — 봉인된 보이드에는 가스가 못 들어와 성장이 멈춘다. 봉인이 단조로워(재료가 늘기만 함) 훑기 한 번으로 봉인시각을 얻을 수 있다.
- **식각** — 반대 방향이고 **훑기 한 번으로는 안 된다** (2026-09-04 2D 검증 완료). 증착의 봉인은 "멈춤"이라 값을 고정하면 끝이지만, 식각의 돌파는 **새 시작점**이라 재계산이 필요하다. 밀봉 보이드를 뚫는 테스트에서 훑기 한 번은 보이드 바닥을 36에 깎았다(정답 26), 측벽 30(정답 26), t=30 시점 식각량 18% 부족. 해법은 **돌파 이벤트마다 새로 열린 빈 공간을 소스로 EDT를 한 번 더 돌려 `arrival = min(기존, 돌파시각 + 새거리)`**. 돌파는 식각당 보통 0~1회라 추가 비용은 EDT 한 번 수준. 검증 스크립트: `scratchpad/etch_monotonicity.py`
- **PR 코팅 / 채우기** — 봉인된 보이드에는 PR이 안 들어간다. 채울 범위를 연결성으로 제한한다.
- **어닐 확산** — 도펀트는 재료를 통해 퍼지고 빈 공간에 막힌다. 연결성 조건이 반대다.

**Why:** 이걸 놓치면 물리적으로 틀린 결과가 나오는데, 화면상으로는 그럴듯해 보여서 발견이 늦다. 실제로 2D 데모 1차판이 이 버그를 갖고 있었다.

**How to apply:** 새 연산자를 설계할 때마다 "이 연산은 무엇과 이어져 있어야 일어나는가"를 먼저 묻는다. 현재까지 파악된 원시연산은 세 개다 — ① 거리 오프셋(증착/식각/어닐), ② 연결성 검사, ③ 높이 기준 채우기/자르기(PR 코팅, CMP).
