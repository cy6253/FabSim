2026-09-04 프로젝트 전반 검토. 문서: https://claude.ai/code/artifact/3ac98b69-0cfc-4926-b498-2afed4c561ab

**핵심 발견: 시뮬레이션 코어는 충분히 설계·검증됐고, 그 주변이 거의 설계되지 않았다.** 층별 성숙도 — 코어(검증 완료) / 실행기(결정만) / 재질·공정 데이터(미설계) / 프로젝트·레시피(미설계) / UI 정보구조(부분) / 마스크 디자이너(부분) / 교육 계층(미설계) / 앱 상태·저장소(미설계) / 테스트·배포(미설계).

**제안한 것 (사용자 결정 없이 진행하기로 한 방향):**
- **재질·공정은 데이터**: 재질 라이브러리(Si·poly·SiO₂·Si₃N₄·Al·Cu·W·TiN·PR…, 종류·산화/실리사이드 가능·D₀·Eₐ·편석계수), 공정 라이브러리(식각액별 선택비·이방성, 슬러리별 제거율, LPCVD/PECVD/PVD/ALD별 기본 커버리지), 물리상수 표(Deal-Grove, Rp·ΔRp). 전부 JSON, 프로젝트에 포함. 기존 Unity의 EtchantConfig/CmpRateConfig/ColorRegistry 값을 초기 데이터로.
- **프로젝트 = JSON 하나**(마스크 PNG base64 내장) + 시뮬레이터 버전. 교사가 레시피를 파일/링크로 배포하는 게 기본 흐름. **예제 레시피가 곧 커리큘럼.**
- **교육 계층이 가장 값진 빈자리**: 코어가 이미 계산하는 것(보이드, 정렬 오차 단락, etch stop, 마스크 소모)을 **진단 메시지**로 노출. 측정 도구(프로브·자·커버리지·사이드월 각·접합 깊이·프로파일 그래프·변경분 하이라이트). 노드 주석. 내보내기(PNG·GIF·표).
- **UI**: 단면 뷰가 주인공(가장 크고 항상 표시), 3D는 보조(절단면·재질별 숨김), 타임라인 가로, 그래프는 좌측 패널. 와이어프레임으로 확정 필요. 마스크 디자이너는 브러시보다 **사각형·다각형·스냅**이 중요.
- **앱 상태**: 프로젝트 상태/시뮬 결과/UI 상태 분리. 편집 undo는 타임라인과 별개. Worker 프로토콜 run/cancel/progress/stepDone(transferable). IndexedDB는 프로젝트·마스크·스냅샷 캐시. **결정성 필수**(난수 없음, 광선 방향 고정, 버전 기록).
- **성능 실측 완료**: 150만 0.71s/단계, 600만 2.15s/단계. 기본 격자 150만 확정 근거. Worker 분할 불필요, 지연 평가가 핵심.
- **메모리 예산**: 600만 격자 상주 ~102MB + 스크래치 ~100MB + 스냅샷 + 지오메트리 ≈ 300~400MB → 교실 기기에 위험. **기본 격자 ~150만(240×100×64) 권고**, 600만은 고해상도 프리셋.
- **테스트**: Python 참조 구현을 오라클로 **골든 테스트**(같은 시퀀스, 재질 배열 해시 비교), 원시연산 단위 테스트(EDT↔브루트포스, FMM↔EDT 균일속도, union-find↔sweep), 연산자 회귀 임계값, 결정성 테스트.
- **기존 Unity 기능 대조에서 빠졌던 것**: 재질별 숨김 토글(MaterialToggle), 마스크 미니맵·격자 라벨 → 추가.
- **로드맵**: M1c(검토 적용, ~1주) → M2(연산자 완성, ~2주) → M3(데이터 모델·편집·React Flow, ~3주) → M4(교육 계층·예제 레시피, ~2~3주) → M5(마칭큐브·배포·PWA, ~1~2주). 합계 10~12주(1인 추정).
- **범위 밖 명시**: 소자 시뮬, 리소 광학, 응력(LOCOS 보류 이유), 결정 방향 식각(훅만), 서버 협업.

**교육 범위 결정 4건 — 확정 (2026-09-04):**
- 기본 격자 **약 150만(240×100×64)**, 600만은 고해상도 프리셋
- 예제 레시피 = **단위공정 실습(트렌치 증착·LOCOS·STI·게이트·콘택/플러그) + 완성형 NMOS 하나.** CMOS 인버터는 범위 밖
- 재질·공정 표는 **사용자 편집 허용**, 프로젝트에 함께 저장 → 표 편집 UI가 M3 범위에 들어감
- 가이드 레슨은 **노드 주석까지만.** 관찰 과제형 레슨 모드는 나중에
설계 단계에서 열린 질문은 LOCOS bird's beak(응력 의존 산화, 보류) 하나만 남았다.

**How to apply:** 다음 구현은 M1c(코어 검토 적용)부터. 새 기능을 논의할 때 이 문서의 층 구조에서 어느 층인지 먼저 자리를 잡는다. 코어를 더 다듬는 것보다 빈 층을 채우는 게 구현 용이성에 더 기여한다.
